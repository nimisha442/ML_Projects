## 📌 Project Overview

Heart disease is one of the leading causes of death worldwide. Early prediction can help in preventive care and improve patient outcomes.
This project builds a machine-learning classification model to predict whether a person is at risk of heart disease using clinical and demographic features.

The dataset used is the UCI Heart Disease Dataset, and multiple classification models are trained and evaluated to choose the best performer.

## 🚀 Features

Data cleaning & preprocessing

Exploratory Data Analysis (EDA)

Feature scaling

Model training using multiple classifiers

Logistic Regression

Decision Tree

Random Forest

Support Vector Machine (SVM)

K-Nearest Neighbors (KNN)

Model evaluation (Accuracy, Precision, Recall, F1-Score, ROC-AUC)

Final model saving using joblib

Interactive predictions (optional: Streamlit/Flask)
